# SOC Analyst Portfolio

Welcome to my cybersecurity portfolio.

I am a Cybersecurity student focused on developing practical skills for an **SOC Analyst Level 1 / Blue Team** role.

This repository showcases hands-on security investigations, defensive security exercises, and a personal SOC home lab built to practice security monitoring, endpoint telemetry collection, detection engineering, alert triage, and incident investigation.

My work focuses on understanding security events, identifying suspicious behavior, collecting supporting evidence, documenting findings, and practicing incident escalation workflows.

## Technical Focus

- Security event monitoring and analysis
- Windows endpoint monitoring with Sysmon
- Centralized log collection and analysis using Splunk
- SPL-based detection searches and alert development
- Network traffic analysis
- PowerShell and process execution investigation
- Security alert triage and incident investigation
- Evidence collection and incident documentation
- Incident tracking and L1-to-L2 escalation exercises

### 2. SOC Home Lab

A multi-system SOC home lab designed to simulate a basic security monitoring and investigation environment.

The laboratory uses a centralized Splunk Enterprise instance to collect and analyze Windows endpoint telemetry generated by Sysmon and forwarded through Splunk Universal Forwarder.

**Infrastructure and technologies:**

- Splunk Enterprise 10.6.1.1
- Splunk Universal Forwarder
- Sysmon
- Windows 10 Pro
- Windows 11
- Kali Linux

**Implemented capabilities:**

- Centralized Windows endpoint event collection.
- Sysmon telemetry monitoring and analysis.
- Splunk dashboards for endpoint monitoring and investigation.
- SPL-based detection searches and scheduled alerts.
- Alert suppression to reduce duplicate notifications.
- Process execution and PowerShell activity monitoring.
- Network connection and file creation monitoring.
- Security investigations supported by event evidence.
- Incident tracking and escalation exercises using GitHub Issues.

**Current documented work:**

- 12 detection use cases across authentication, process execution, network activity, and remote access.
- 5 documented security investigations (INC-001 to INC-005).
- A four-tab Splunk Dashboard Studio monitoring dashboard.
- Architecture, configuration, and data collection documentation.
- Incident tracking and a PowerShell investigation playbook.
