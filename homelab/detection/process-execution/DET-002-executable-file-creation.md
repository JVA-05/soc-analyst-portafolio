# DET-002 — Executable File Creation

## Objective

Identify the creation of executable files, installers, and script files on the monitored Windows endpoint.

This detection helps analysts identify potentially suspicious file drops and establish an initial investigation point for files created in locations such as temporary directories, user profile folders, and download directories.

File creation alone does not establish malicious activity or prove that a file was executed.

## Data Sources

## Detection Logic

The detection searches for Sysmon Event ID 11 and filters file creation events based on selected executable and script extensions.

Included extensions:

- **Executable files:** `.exe`, `.com`, `.scr`
- **Libraries and drivers:** `.dll`, `.sys`, `.ocx`, `.cpl`
- **Installers:** `.msi`, `.msp`
- **Windows scripts:** `.bat`, `.cmd`, `.ps1`, `.psm1`, `.vbs`, `.vbe`, `.js`, `.jse`, `.hta`

The search extracts the file extension and displays the process and file information needed for initial triage.

## SPL Query

```spl
index=sysmon host="DESKTOP-1BDISO6" EventCode=11
| where match(TargetFilename, "(?i)\.(exe|dll|sys|scr|com|msi|msp|cpl|ocx|bat|cmd|ps1|psm1|vbs|vbe|js|jse|hta)$")
| eval FileExtension=lower(mvindex(split(TargetFilename, "."), -1))
| table _time host User Image ProcessId ProcessGuid TargetFilename FileExtension
| sort - _time
```

## Investigation Guidance

When an event is identified, the analyst should:

1. Identify the created file and its full path.
2. Review the user associated with the event.
3. Examine the `Image` field to identify the process responsible for creating the file.
4. Determine whether the file was created in a suspicious location, such as a temporary directory or an unexpected user profile directory.
5. Correlate the event with Sysmon Event ID 1 to determine whether the file was subsequently executed.
6. Review related network activity and other endpoint events when suspicious behavior is identified.

## False Positives and Limitations

Legitimate software installations, application updates, administrative activity, and normal script execution can generate matching events.

Important limitations:

- Event ID 11 identifies file creation, not execution.
- File extensions can be misleading and do not establish the actual file type.
- The detection does not inspect file contents or calculate file hashes.
- Files with extensions outside the configured list are not included.
- A matching event does not independently establish malicious activity.
